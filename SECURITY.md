# Sécurité du site public

Toute exposition suspectée de contenu privé doit entraîner l'arrêt du
déploiement et, si nécessaire, la désactivation temporaire de GitHub Pages.

Ne pas corriger uniquement le HTML généré. Corriger la source privée, renforcer
le contrôle concerné, reconstruire intégralement `site/`, puis publier après
nouvelle approbation humaine.
